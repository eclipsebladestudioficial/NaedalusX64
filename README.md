# NaedalusX64

NaedalusX64 is a Nintendo 64 emulator for the PlayStation 2, based on DaedalusX64.

This is an unofficial PS2 version, originally created by **belek666** and modified by Eclipse Blade Studio.

I have resumed development of this PS2 version with the goal of fixing bugs, improving compatibility, and optimizing performance, aiming to get as many games as possible running at full speed.

## Features:

- Still under development.
- Distorted graphics in some games.
- Some games may not work or may exhibit serious issues.
- Among other aspects...

## How to Use

Download the version available under the "Releases" tab.

Place the downloaded files/folders in the root directory of your storage device (`mass`) or in the `Apps` folder for OPL.

ROMs should be placed in a directory named `Roms` or `N64`.
