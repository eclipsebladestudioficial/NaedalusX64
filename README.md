# NaedalusX64

NaedalusX64 is a Nintendo 64 emulator for Linux and PSP, with plans to port to Windows, Mac, PS Vita among other platforms. The PSP port is noteworthy for being the fastest N64 emulator ever on the platform, achieving close to or even full speed in many titles.

This is an unofficial PS2 port originally made by **belek666**.

I picked up the PS2 port to fix bugs, improve compatibility and optimize performance, with the goal of getting as many games as possible running at full speed.

## Features:

- Still experimental
- No Sound
- Distorted Graphics in many games
- Most games may not work or contain serious issues
- Many other things..

## Compatibility list

### Boots

- Super Mario 64
- Ridge Racer 64

### Does not boot

- GoldenEye 007
- Star Fox 64
- The Legend of Zelda - Majora's Mask

## Usage

Download the release from the "Releases" tab.

Put files/folders from the download on the root directory of mass.

ROMs go in the `Roms` directory.
